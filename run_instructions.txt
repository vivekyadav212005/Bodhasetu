Frontend (Vite + React + Tailwind)
1) In a new terminal:
     cd frontend
     npm install
     VITE_API_URL="http://localhost:8000" npm run dev

Backend (FastAPI)
1) In project root:
     source myenv/bin/activate
     uvicorn backend.main:app --reload --port 8000

Notes
- Ensure MongoDB and Qdrant are running and accessible.
- CORS is enabled for localhost dev ports 5173/3000.
- To enable email fetching, set these in .env:
     ORG_DOMAIN=kmrl.org
     EMAIL_ALLOWED_DOMAINS=kmrl.org
     EMAIL_HOST=imap.example.com
     EMAIL_PORT=993
     EMAIL_USER=your-user@example.com
     EMAIL_PASS=your-password
     EMAIL_FOLDER=INBOX
# 1. Clone repo
git clone git@github.com:<your-username>/Bodhasetu.git
cd Bodhasetu

# 2. Setup virtual environment
python3 -m venv myenv
source myenv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Create .env file at project root
# Example .env
# MONGO_URI=mongodb://localhost:27017
# MONGO_DBNAME=bodhasetu
# QDRANT_URL=http://localhost:6333
# EMBED_MODEL=all-MiniLM-L6-v2
# TESSERACT_CMD=/usr/local/bin/tesseract  # if needed
# GROQ_API_KEY=sk-...
# GROQ_API_URL=https://api.groq.com/openai/v1/chat/completions
# GROQ_MODEL=mixtral-8x7b-32768

# 5. Start MongoDB (Homebrew on macOS)
brew services start mongodb-community@6.0

# 6. Start Qdrant via Docker
docker run -p 6333:6333 qdrant/qdrant

# 6.1 Install Tesseract OCR (for scanned PDFs)
# macOS (Homebrew):
# brew install tesseract

# 7. Run FastAPI server
uvicorn backend.main:app --reload

# 8. (Optional) Test upload
curl -X POST "http://127.0.0.1:8000/upload" \
     -F "file=@/path/to/test.pdf" \
     -F "department=Engineering"

# 9. (Optional) Semantic search
curl "http://127.0.0.1:8000/search?q=project%20plan&k=5"

# 10. (Optional) Ask a question with LLM
curl -X POST "http://127.0.0.1:8000/query" \
     -H 'Content-Type: application/json' \
     -d '{"query":"What actions are pending for furniture procurement?","top_k":8}'
